# SAKiR Framework Baselines

Packaged SAKiR framework baseline downloads.

[Read baseline summaries and release notes](baselines-notes.md)

## Latest baseline

[Download baseline 32](https://github.com/SakirVarli/framework-baselines/raw/refs/heads/main/baselines/SAKiR_GUI_baseline_32.zip)

### Usage type 1 — Start a new project

1. Download the baseline ZIP.
2. Extract the entire ZIP into a new project folder.
3. Open the extracted folder and run **designer.exe**.

### Usage type 2 — Upgrade an existing project

Use the upgrade wizard to move an existing project from an older baseline to a newer one.

1. Save your work and back up important project files.
2. Download the newer baseline ZIP and leave it zipped.
3. Open your existing application and choose **File > Upgrade…**.
4. Select the downloaded ZIP, then review compatibility, release notes, file comparisons, and replacement options. Leave replacement options cleared to preserve locally modified files, callbacks, helpers, and project settings. Select replacements only for content you intend to overwrite.
5. Finish the wizard to verify and apply the update. The upgrader creates a backup and restarts the application.
